# CARCHECK Card Bridge v3 — จำการเชื่อมต่อ

ชุดซอร์ส C# สำหรับ Windows x64 + .NET 10 SDK ยังไม่มี EXE ที่คอมไพล์แล้ว

## อัปเดตครั้งแรก
1. ปิดหน้าต่าง Card Bridge เดิมทั้งหมด
2. แตก ZIP นี้เป็นโฟลเดอร์ใหม่ แล้วเปิด Build.cmd รอข้อความสำเร็จ
3. เปิด Run-Web.cmd และคงหน้าต่างโปรแกรมไว้
4. ในหน้าทดสอบที่เปิดขึ้น กด “คัดลอกรหัสเชื่อมต่อเว็บ”
5. เปิด https://pornchaibank.github.io/carcheck-demo/ เข้าสู่ระบบเดโมด้วยชื่อ/รหัสอะไรก็ได้ที่ไม่ว่าง
6. บัญชีของฉัน → บันทึกการมาทำงาน → วางรหัส → ติ๊ก “จำการเชื่อมต่อบนเครื่องนี้” → เชื่อมต่อเครื่องอ่าน
7. ถ้าเบราว์เซอร์ถาม ให้อนุญาตเข้าถึงเครือข่ายภายในสำหรับการเชื่อมโปรแกรมบนเครื่องนี้
8. เสียบบัตร แล้วกดบันทึก ข้อมูลบนเว็บแก้ไขไม่ได้

## ครั้งถัดไป
- เปิด Run-Web.cmd ตามเดิม ไม่ต้อง Build ใหม่ทุกครั้ง
- เข้าเมนูบันทึกการมาทำงานด้วยเบราว์เซอร์/โปรไฟล์เดิม ระบบจะเชื่อมเครื่องอ่านเดิมอัตโนมัติ
- ถ้าเข้าเว็บก่อนเปิดโปรแกรม ให้เปิด Run-Web.cmd แล้วกด “เชื่อมต่อเครื่องเดิมอีกครั้ง”
- ยังไม่ได้ตั้งให้โปรแกรมเริ่มพร้อม Windows
- รุ่น 2 ใช้เว็บใหม่ได้ แต่จะต้องกรอกรหัสใหม่หลังปิดโปรแกรม รุ่น 3 จึงจะจำข้ามการปิดโปรแกรมได้

## ข้อมูลที่จำและการลืม
- เว็บจำเฉพาะรหัสเชื่อมต่อและชื่อเครื่องอ่านใน localStorage ของเบราว์เซอร์ ใช้บนเครื่องที่ไว้ใจได้เท่านั้น
- ไม่เก็บชื่อบุคคล เลขบัตร หรือรายการมาทำงานลง localStorage/ฐานข้อมูล/ไฟล์
- ฝั่ง Windows เก็บรหัสเชื่อมต่อแบบเข้ารหัส DPAPI สำหรับผู้ใช้ Windows คนปัจจุบันที่ %LOCALAPPDATA%\CARCHECK\CardBridge\pairing.dpapi
- ปุ่ม “ตัดการเชื่อมต่อ” พักการเชื่อมต่อครั้งนี้ การเปิดเมนูใหม่ยังเชื่อมเองหากจำไว้
- ปุ่ม “ลืมการเชื่อมต่อ” ลบรหัสจากเบราว์เซอร์นี้และตัดการเชื่อมต่อ
- หากต้องการยกเลิกรหัสเดิมทุกเบราว์เซอร์ ให้ปิดโปรแกรมแล้วเปิด Reset-Pairing.cmd จากนั้นจับคู่ใหม่
- เปลี่ยนโปรไฟล์เบราว์เซอร์/ใช้โหมดไม่ระบุตัวตน/ล้างข้อมูลเว็บไซต์ ต้องจับคู่ใหม่
- รหัสเป็นสิทธิ์อ่านบัตรผ่านโปรแกรม อย่าส่งให้ผู้อื่น ผู้ใช้เบราว์เซอร์เดียวกันบนเครื่องนี้ใช้การเชื่อมต่อที่จำไว้ได้
- เว็บอื่นภายใต้ origin https://pornchaibank.github.io มีขอบเขต localStorage เดียวกัน จึงควรคงเฉพาะแอปที่ไว้ใจได้บน origin นี้

## ขอบเขตเดโม
- ชื่อ/เลขบัตรแบบปิดบางส่วนแสดงชั่วคราวในหน่วยความจำ เว็บไม่มีการส่งขึ้น GitHub หรือฐานข้อมูล
- รีเฟรช/ออกจากระบบล้างตาราง ส่วน Bridge จำผลยืนยันล่าสุดของบัตรที่ยังเสียบไว้ชั่วคราวเพื่อไม่ทำรายการซ้ำจากการส่งซ้ำ
- อ่านบัตรซ้ำก่อนยืนยัน ปฏิเสธข้อมูลเก่าหลังถอดหรือเปลี่ยนบัตร
- ตรวจซ้ำบัตร/วันภายในรอบเปิดเว็บ ไม่ใช่ระบบลงเวลาถาวร เวลาอ้างอิง Windows
- หน้าทดสอบท้องถิ่นเดิมแสดงเลขบัตรเต็มเพื่อทดสอบเท่านั้น ไม่มีการบันทึกไฟล์
- เมนูอื่นยังใช้ข้อมูลสมมติ ไม่มีการส่ง LINE หรือเชื่อมระบบจริง
- โปรแกรมรับการเชื่อมต่อเฉพาะ 127.0.0.1:17861 พร้อมตรวจรหัสและ origin ตามเดิม

## การตรวจสอบ
- React bundle สร้างสำเร็จ และชุดทดสอบ JavaScript 8 รายการผ่าน (สถานะบัตร/รายการซ้ำ/จำค่าข้ามการเปิด/ลืมค่า/พื้นที่จัดเก็บใช้ไม่ได้/ข้อมูลผิดรูปแบบ)
- Build.cmd มี APDU, attendance และ Windows DPAPI self-test ให้รันก่อนใช้
- ยังไม่ได้คอมไพล์หรือทดสอบ C# v3 กับฮาร์ดแวร์ในสภาพแวดล้อมผู้จัดทำ ต้อง Build และทดลองบน Windows จริง
- โฟลเดอร์ web-source เป็นซอร์ส React ที่เกี่ยวข้องสำหรับตรวจสอบ ไม่ใช่ชุดเว็บพร้อม asset ครบ

เอกสาร DPAPI: https://learn.microsoft.com/en-us/windows/desktop/api/Dpapi/nf-dpapi-cryptprotectdata
